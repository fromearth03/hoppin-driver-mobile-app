## 1. The live outage — fix this first

**No driver can upload a document on any real device.**

`POST /drivers/me/documents/upload-url` returns 200 with:

```
http://minio:9000/test-verifier/driver-docs/<uid>/dvla_license/<uuid>.jpg?X-Amz-...
```

Three faults in one URL:

1. `minio` is an internal Docker hostname. Verified from outside the box:
   `Could not resolve host: minio`. No public alias exists either
   (`storage.` / `minio.` / `s3.hoppin.tech` all unresolvable).
2. It is plain `http`. Android release builds block cleartext by default.
3. The bucket is `test-verifier`, which reads as a dev leftover.

**The app is not at fault.** Its three-step flow (presign → PUT → confirm,
`lib/features/documents/logic/upload_controller.dart:105`) is correct. Step 2
can never connect.

**The fix already half-exists in the backend.** `internal/storage/s3.go` has
`PutTo`/`GetFrom`, and the comment on `PutTo` describes this exact problem.
Avatars already upload that way. Full spec, plus the alternative if MinIO is
to be exposed publicly, is in `docs/BACKEND-ASK-ROUND6-2026-09-03.md`.

**Waiting on:** the backend dev to pick option A (proxy) or B (public MinIO).

**604 tests pass.** No known regressions.

### The two real bugs behind "Something went wrong"

1. `AUTH_REQUIRED` — the ordinary expired token, and the most common 401
   there is — had **no copy anywhere in the app**, so it fell through to the
   generic fallback. Verified against the live API: every guarded route
   returns `{"code":"AUTH_REQUIRED"}` on a stale token.
2. `parseError` labelled **any** non-500 with an unparseable body as
   `NOT_FOUND`. So a 401 behind a gateway page read as "That record no longer
   exists" — wrong, and pointing away from the fix. 401/403 now map to
   themselves; a code the server actually states still wins, which is what
   keeps `SESSION_REPLACED` distinct.

### Why screens were blanking

Every screen used `AsyncValue.when`, which routes on the **current** state —
so a refresh over data the app already held took the loading branch and
blanked to a spinner. On a polling app that is every tick, every tab change,
every pull-to-refresh. Mid-trip it threw away the map, the rider card and the
action button.

`AsyncView` (`lib/shared/widgets/async_view.dart`) asks value-first: held
value → blocking error → cold start. Applied to Home, Stats, Profile,
Settings, Payout, Trip, Chat, ticket thread.

Also fixes a latent crash this exposed: Profile seeded its phone field from
`build`, and assigning `.text` fires the controller listener → `setState`
during build.

## 7. Gotchas worth keeping

- **Cloudflare blocks curl's default UA** with `error code: 1010`, which looks
  exactly like a backend 403 and cost twenty minutes. Send a browser UA:
  ```sh
  curl -H "User-Agent: Mozilla/5.0 (Linux; Android 13) Chrome/120 Mobile Safari/537.36" \
       -H "Authorization: Bearer $TOKEN" \
       https://api.hoppin.tech/api/v1/drivers/me/status
  ```
- **Supabase JWTs expire in 1 hour.** A token minted at the start of a session
  is dead by the end, and every route then answers `AUTH_REQUIRED` — which
  looks like a permissions bug and is not.
- **`test/features/onboarding/onboarding_controller_test.dart`** is
  timing-flaky under full parallel load. Passes alone. Not a regression.
- **Browser tooling was down** this session (Playwright MCP and the Chrome
  extension both failed to connect), so nothing here was verified by driving
  the UI — only by live API calls and source reading.
